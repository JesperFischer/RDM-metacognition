The Heuristic Model of Perceptual Decision Making and Metacognition

Model Overview

This simulator implements a static heuristic model of how people make perceptual decisions and rate confidence in those decisions. The model is built on Signal Detection Theory but introduces choice variability to explain how people can recognize errors even with perfect information about the decision.

Core Components

1. Perceptual Evidence

On each trial, a person perceives noisy evidence about a stimulus:

ei ~ N(Di · Xi - β, σe)

Where:

  • Di: True stimulus direction (-1 or +1)
  • Xi: Stimulus strength/coherence (0 to 1)
  • β: Bias in the evidence (can shift psychometric function)
  • σe: Evidence noise - governs accuracy

2. Stochastic Decision Rule

Unlike traditional SDT models with a fixed criterion, this model assumes a variable criterion:

ci ~ N(0, σk)
Action = 1 if ei > ci, else -1

This means:

  • σk: Criterion variability - allows errors even with good evidence
  • Creates choice uncertainty independent of evidence quality
  • Enables error monitoring without assuming independent information sources

3. Confidence Ratings

Confidence is computed as the person's subjective probability of being correct:

ri ~ N(ei, σm)
Confidence = P(Correct | ri, action)

Where:

  • ri: Noisy readout of internal evidence
  • σm: Metacognitive noise - degree of introspective access
  • Implemented using logistic (inverse logit) function to map evidence to probability

Key Model Parameters

Parameter Symbol Meaning Effect
Evidence Noise σe Perceptual noise ↑ noise = flatter psychometric, lower accuracy
Choice Noise σk Criterion variability ↑ noise = more random choices, enables error monitoring
Metacognitive Noise σm Introspection accuracy ↑ noise = weaker confidence-accuracy relationship
Bias β Evidence bias ↑ bias = shifts psychometric & confidence curves

What the Plots Show

Psychometric Function

Shows how the probability of saying "choice = 1" changes with stimulus strength. This reveals:

  • Slope: Governed by both σe and σk - steeper = better discrimination
  • Threshold: Where 50% choice is made - affected by bias β

Confidence by Accuracy

Shows mean confidence ratings as a function of stimulus strength, separately for correct and incorrect responses. This reveals:

  • Error monitoring: Low confidence on error trials (especially at extreme stimuli)
  • Confidence calibration: Proper rise of confidence with stimulus strength
  • Metacognitive sensitivity: Gap between correct and error confidence
